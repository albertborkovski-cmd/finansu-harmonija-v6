# Finansų harmonija V6

V6 testavimo versija. Vieša testavimo nuoroda automatiškai atnaujinama po kiekvieno pakeitimo, įkelto į `main` šaką.

## Paleidimas

```bash
npm install
npm run dev
```

Vietinis adresas: <http://127.0.0.1:5185/>

## Publikavimas

Publikavimą į „GitHub Pages“ automatiškai atlieka `.github/workflows/deploy-pages.yml`. Testuotojui nereikia terminalo ar projekto diegimo – užtenka atidaryti viešą nuorodą.
